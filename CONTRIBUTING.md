# Contributing

## Issues are welcome

Open an issue at <https://github.com/juliedavila/plumb/issues> for a bug, a wrong statement in the docs, a command that does not do what its help says, or a question the docs could not answer. Name the Plumb version and the command you ran.

## Pull requests are not merged

This repository is published from another source tree at each release, so a change made here would be overwritten by the next one. Describe the change in an issue instead. If it is taken up, it ships in the next release and the changelog says so.

## Security problems

Report them privately, as [SECURITY.md](SECURITY.md) describes. Never in a public issue.
